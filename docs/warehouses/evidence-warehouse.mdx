title: 'Evidence Warehouse'
description: 'Evidence''s built-in, fully managed cloud warehouse.'
---

The **Evidence Warehouse** is Evidence's built-in, fully managed cloud warehouse. You connect a data source once, Evidence extracts the data into the warehouse, and every report queries it from there — fast, with no infrastructure for you to run. You choose which region the data is stored in (see [Storage Regions](/data-sources#storage-regions)).

Connectors are how you get data into the Evidence Warehouse. You connect to your data source once, then use that data across all your reports.

Evidence supports different types of connectors: **Databases**, **Object Storage**, **Data Lakes**, **Flat Files**, and **Applications**.

If you'd rather have Evidence query a warehouse you own directly — without extracting data into the Evidence Warehouse — use a [native connector](/data-sources#direct-connectors) instead.

See the [Evidence Warehouse overview](/data-sources) for how it works and the full list of connectors that load data into it.
