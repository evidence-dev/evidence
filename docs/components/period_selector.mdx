## Using the Filter Variable

Reference this filter using `{{filter_id}}`. The value returned depends on where you use it.

| Context | Default Property | No Selection | Result |
|---------|-----------------|--------------|--------|
| Inline SQL query | `.between` |  | `BETWEEN toDate('2026-07-01') AND toDate('2026-07-31')` |
| `where` attribute | `.between` |  | `BETWEEN toDate('2026-07-01') AND toDate('2026-07-31')` |
| Text / Markdown | `.label` |  | `Jul 2026` |

### Available Properties

You can also access specific properties using `{{filter_id.property}}`:

#### .between
A WHERE-clause fragment covering the period in the active SQL dialect: `BETWEEN <start> AND <end>`.

**Example value:** `BETWEEN toDate('2026-07-01') AND toDate('2026-07-31')`

#### .label
The period’s display label, e.g. `Jul 2026`.

**Example value:** `Jul 2026`

#### .start
The first date of the period, as an expression for the active SQL dialect. Use `start_label` in prose.

**Example value:** `toDate('2026-07-01')`

#### .end
The last date of the period (inclusive), for the active SQL dialect. Use `end_label` in prose.

**Example value:** `toDate('2026-07-31')`

#### .start_label
The first date of the period, formatted for display.

**Example value:** `Jul 1, 2026`

#### .end_label
The last date of the period (inclusive), formatted for display.

**Example value:** `Jul 31, 2026`

#### .filter
A complete SQL filter expression for the period. Requires `value_column`; resolves to `true` without it.

**Example value:** `order_date >= toDate('2026-07-01') AND order_date <= toDate('2026-07-31')`

#### .key
The period’s stable identifier, e.g. `2026-07`. Use it to key per-period records.

**Example value:** `2026-07`

#### .grain
The period grain, e.g. `month`.

**Example value:** `month`
