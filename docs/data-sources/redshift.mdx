## Connection String Format

```
redshift://<USER>:<PASSWORD>@<HOST>:<PORT>/<DATABASE>?sslmode=require&options=-csearch_path%3D<SCHEMA>
```

The `sslmode` option can be one of:

```
disable, allow, prefer, require, verify-ca, verify-full
```
