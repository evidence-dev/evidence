## Add New Connector

To add a MongoDB connector:
1. Select **Connectors** in the left sidebar and click "New Connector"
2. Select **MongoDB** from the list of connectors
3. Enter a connection name and click "Connect via Fivetran"
4. Complete the authorization flow in the popup window
5. Select the schemas and tables you want to sync
6. Configure your sync schedule
